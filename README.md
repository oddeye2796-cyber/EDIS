# EDIS 수발주

건강기능식품 원부재료 수발주 업무 자동화 플랫폼의 데모입니다.
이메일, 카톡, 문자, 전화로 들어온 주문을 한 곳에 모으고, 발주 승인부터 입고, 수주부터 출고, 이카운트 전표 등록까지 한 흐름으로 처리합니다.

## 데모에 들어 있는 것

- **주문 올리기 (모바일)**: 영업 담당자가 받은 카톡·문자·메일을 휴대폰에서 붙여 넣거나 캡처 사진으로 올리고, 진행 단계를 확인
- **주문 접수함**: 올라온 원문을 AI가 거래처·품목·수량·납기로 정리하고, 수발주 담당자가 확인해 발주서나 수주로 전환
- **처리 흐름 표시**: 발주·수주마다 지금 머무른 단계를 진행 바로 표시, 대시보드에는 단계별 대기 건수
- **발주 (매입)**: 작성 → 오피스 관리자 승인 → 공장 관리자 확인 → 공급사 발송 → 입고(부분 입고 포함)
- **수주 (매출)**: 등록 → 확정 → 출고 준비 → 출고(부분 출고 포함)
- **로트·유통기한**: 입고 시 로트번호, 제조일, 유통기한, COA 기록. 90일 내 만료 표시
- **이카운트 연동**: 입고 완료 시 구매 전표, 출고 완료 시 판매 전표 전송. 인증키가 없으면 모의 모드로 요청 내용만 기록
- **대시보드·알림**: 역할별 할 일, 납기 임박·지연, 처리 전 주문

로그인은 데모용으로 사용자(오피스 관리자, 공장 관리자, 수발주 담당자, 영업 담당자)를 고르는 방식입니다. 운영 전환 시 Neon Auth로 바꿉니다.

## 실행

```bash
npm install
echo 'DATABASE_URL="postgresql://..."' > .env.local   # Neon 연결 문자열
npm run db:setup:demo   # 스키마 + 기본 데이터 + 시연용 진행 중 데이터 (빈 DB에서 한 번)
npm run dev
```

화면은 반응형이라 휴대폰 브라우저에서 그대로 쓸 수 있고, 홈 화면에 추가하면 "주문 올리기" 화면이 앱처럼 열립니다.

`npm run db:setup`은 시연용 진행 중 데이터 없이 스키마와 기본 데이터만 넣습니다.

## 환경 변수

| 이름 | 설명 |
| --- | --- |
| `DATABASE_URL` | Postgres 연결 문자열 (Neon) |
| `ANTHROPIC_API_KEY` | 있으면 Claude가 주문 원문을 정리. 없으면 간단한 규칙 기반으로 정리 |
| `ECOUNT_COM_CODE`, `ECOUNT_USER_ID`, `ECOUNT_API_CERT_KEY` | 이카운트 오픈API 정보. 없으면 모의 모드 |

## 구조

- `db/schema.sql`, `db/seed.sql`, `db/demo.sql`: 스키마와 데이터
- `lib/`: DB 접근, 데모 로그인, 상태 이력·알림, 이카운트 연동
- `app/`: 화면과 서버 액션 (Next.js App Router)
