## 1. 시작하기

EDIS는 주문이 들어와서 이카운트 전표가 될 때까지를 다섯 역할이 이어서 처리하는 시스템입니다. 내 차례가 오면 알림이 오고, 내 차례가 아닌 버튼은 보이지 않습니다.

**로그인:** 주소로 들어가 내 이름 버튼을 누릅니다. 데모에서는 "사용자 전환"으로 다른 역할로 바꿔 볼 수 있습니다.

| 역할 | 데모 계정 | 주로 하는 일 | 처음 열리는 화면 |
| --- | --- | --- | --- |
| 영업 담당자 | 최영업 | 거래처 주문 전달, 출하 지시, 내 출하 진행 확인 | 주문 올리기 |
| 수발주 담당자 | 이담당 | 접수함 정리, 발주서·수주 작성, 수주 확정, 발주서 발송 | 대시보드 |
| 오피스 관리자 | 김오피스 | 발주 승인·반려, 전체 현황 관리 | 대시보드 |
| 공장 관리자 | 박공장 | 발주 확인, 입고, 출고 준비·출고, 재고 | 대시보드 |
| 경영진 | 정대표 | 매출·매입 추세와 챙길 일 확인 | 경영 현황 |

**화면 공통 규칙**

- 왼쪽 메뉴는 역할마다 다르게 보입니다. 내 일과 관련된 메뉴만 나옵니다.
- 문서 화면 위의 단계 막대가 지금 어느 단계인지 보여줍니다. 내 차례가 아니면 "지금은 ○○가 ○○할 차례입니다"라고 나옵니다.
- 대시보드의 단계 칩(주문 접수, 오피스 승인 같은 네모)을 누르면 그 단계에 머문 건만 모아 볼 수 있습니다. 흐린 칩은 내 권한 밖이라 눌리지 않습니다.
- 잘못 눌렀거나 다른 사람이 먼저 처리한 문서는 화면 위에 빨간 안내가 뜹니다. 새로 고침하면 지금 상태가 보입니다.
- 거래처와 품목은 이카운트가 원본입니다. EDIS에서는 조회만 하고, 바꿀 때는 이카운트에서 고칩니다.

## 2. 영업 담당자

영업 담당자는 휴대폰으로 주문을 올리고, 내가 보낸 출하가 어디까지 왔는지 확인합니다. 메뉴는 주문 올리기, 출하 지시, 내 출하 현황, 알림 네 개입니다.

### 거래처에게 받은 메시지 전달하기 (주문 올리기)

내용이 정리되지 않은 카톡·문자·메일 주문을 그대로 넘길 때 씁니다.

1. **주문 올리기 > 받은 메시지 전달**을 엽니다.
2. 받은 메시지를 붙여 넣거나 캡처 사진을 올립니다.
3. 어디서 받았는지(카톡·문자·이메일·전화)와 고객 주문인지 원부재료 구매인지 고릅니다.
4. 급한 건이면 "거래처·메모 추가"에 적습니다. **보내기**를 누르면 수발주 담당자의 접수함으로 갑니다.

아래 "내가 올린 주문"에서 담당자 확인 대기, 수주 등록 같은 상태를 볼 수 있습니다.

### 출하 지시 보내기

어느 거래처에 무엇을 몇 개 보낼지 정해져 있을 때 씁니다. 보내면 바로 수주로 등록돼 재고 확인으로 넘어갑니다.

1. **출하 지시**를 열고 납품할 거래처를 고릅니다.
2. 품목과 수량을 넣습니다. 품목이 더 있으면 **+ 품목 추가**, 줄을 빼려면 줄 오른쪽 **−**를 누릅니다.
3. 납품일과 메모를 넣고, 급하면 **긴급**에 체크합니다.
4. 다른 거래처도 같이 보낼 때는 **+ 다른 거래처도 함께 보내기**를 누르고 같은 방법으로 채웁니다. 납품일은 앞 칸 값이 미리 들어갑니다.
5. **출하 지시 보내기**를 누릅니다. 거래처마다 출하 지시가 하나씩 등록되고, 내 출하 현황으로 이동합니다.

**계약해 둔 물량을 나눠 보낼 때:** 출하 지시 화면의 "기존 수주에서 나눠 보내기"에서 수주를 고릅니다. 남은 수량이 보이고, 이번에 보낼 수량만 넣으면 됩니다. 남은 수량보다 많이는 보낼 수 없습니다.

### 내 출하 현황 보기

- 위쪽 탭에서 진행 중, 지연, 완료(30일), 전체를 골라 봅니다. 지연 숫자가 빨간색이면 먼저 확인하세요.
- 카드 오른쪽 위 배지는 납기까지 남은 날(D-3), 오늘 납품, n일 지연, 출고일 중 하나입니다.
- 굵은 한 줄이 지금 상태입니다. 예) "공장에서 출고 준비 중이에요"
- 네 단계(접수 → 확정 → 출고 준비 → 출고 완료)에 끝난 날짜가 찍힙니다.
- 주황색 상자에 "재고가 부족해…"가 보이면 생산이나 발주를 기다리는 건이라 납기가 늦어질 수 있습니다. 거래처에 미리 알려 두세요.
- 같은 주문을 또 보낼 때는 카드 아래 **같은 내용으로 다시 보내기**를 누릅니다.

### 알림

내 출하 지시가 확정, 출고 준비 시작, 일부 출고, 출고 완료, 취소되거나 납기가 지나면 알림이 옵니다. 내 출하 현황 맨 위 "새 소식"에 모이고, 확인한 뒤 **확인했어요**를 누르면 지워집니다.

## 3. 수발주 담당자

수발주 담당자는 들어온 주문을 문서로 만들고, 승인·확인이 끝난 발주서를 공급사에 보냅니다. 하루를 대시보드의 "새 알림"과 "내가 처리할 발주서"로 시작하세요.

### 매일 할 일 순서

1. **주문 접수함** 정리: 영업이 올린 주문과 메일로 들어온 주문을 문서로 바꿉니다.
2. **수주 확정 대기** 처리: 재고를 보고 확정하거나 부족분을 요청합니다.
3. **공급사 발송 대기** 처리: 공장 확인이 끝난 발주서를 보냅니다.
4. 반려된 발주서가 있으면 고쳐서 **다시 승인 요청**합니다.

### 주문 접수함에서 문서 만들기

1. 접수함을 열면 처리 전 주문이 위에, 긴급 건이 맨 위에 있습니다.
2. AI 정리 칸에서 거래처·품목·수량·납기를 확인합니다. 이상하면 **다시 정리**를 누릅니다.
3. **수주로 등록** 또는 **발주서 작성**을 누르면 정리된 내용이 채워진 화면이 열립니다. 확인 후 저장합니다.
4. 주문이 아닌 메시지는 **무시**합니다.

사무실로 바로 온 전화 주문은 접수함 위 "사무실에서 직접 받은 주문 기록하기"를 펼쳐 적습니다. 품목을 직접 알고 있으면 **발주 > 발주서 작성** 또는 **수주 > 수주 등록**에서 바로 만들어도 됩니다.

### 수주 확정과 재고 부족

1. **수주 > 확정 대기**에서 수주를 엽니다.
2. 재고 표에서 품목별 보유·예약·입고 예정·부족 수량을 확인합니다.
3. 충분하면 **수주 확정**을 누릅니다. 공장 관리자에게 출고 준비 요청이 갑니다.
4. 부족하면 **부족분 발주서 만들기**(원부재료)나 **공장에 부족분 생산 요청**(완제품)을 누릅니다. 발주서는 공급사별로 자동으로 만들어져 오피스 승인으로 갑니다.

### 발주서 공급사에 보내기

1. **발주 > 공급사 발송 대기**에서 발주서를 엽니다.
2. 발송 방법(이메일·문자·팩스)을 고르면 거래처 연락처가 채워집니다.
3. **발주서 발송**을 누릅니다. 공장 관리자에게 입고 준비 알림이 갑니다. (데모에서는 실제로 보내지 않습니다.)

### 그 밖의 화면

| 화면 | 언제 쓰나 |
| --- | --- |
| 엑셀 일괄 등록 | 여러 건을 엑셀로 한 번에 올릴 때. 양식 파일을 내려받아 채웁니다. |
| 재고 > 로트·유통기한 | 로트별 남은 수량과 유통기한 확인. 90일 안에 끝나는 로트를 챙깁니다. |
| 기준 정보 > 거래처·품목 | 조회만 합니다. 이카운트에서 바꾼 내용은 **이카운트에서 다시 받기**로 가져옵니다. 품목의 현장 별칭(예: "비타민C" → 아스코르빈산)만 여기서 고칩니다. |
| 연동 > 이메일 | 주문 메일함을 **새 메일 확인**으로 읽어 접수함에 넣습니다. |
| 연동 > 이카운트 | 입고·출고 때 자동으로 등록된 구매·판매 전표 기록을 봅니다. |
| 분석 > 리포트 | 거래처·품목·접수 채널별 집계 |

## 4. 오피스 관리자

오피스 관리자는 발주서를 승인하거나 반려하고, 전체 흐름이 막히지 않았는지 봅니다. 발주서 작성·수주 확정·발송도 할 수 있어 담당자가 없을 때 대신합니다.

### 발주서 승인·반려

1. **승인 > 발주 승인 대기**를 엽니다. 대시보드의 "오피스 승인" 칩을 눌러도 같습니다.
2. 발주서의 공급사, 품목, 수량, 단가, 납기를 확인합니다. 재고 부족으로 자동 생성된 발주서는 어느 수주에서 나왔는지 표시됩니다.
3. 문제가 없으면 **오피스 승인**을 누릅니다. 공장 관리자에게 확인 요청이 갑니다.
4. 고칠 게 있으면 사유를 적고 **반려**합니다. 사유가 알림에 붙어 담당자에게 갑니다.

승인 대기가 하루를 넘기면 "[승인 대기]" 알림이 옵니다.

### 현황 보기

- **대시보드:** 단계별로 몇 건이 머물러 있는지 주황색 숫자로 봅니다. 칩을 누르면 그 목록으로 갑니다.
- **납기 임박·지연:** 3일 안에 납기이거나 지난 건입니다. 지연 건은 알림으로도 옵니다.
- **현황 메뉴:** 발주·수주·접수함 전체 목록. 상태로 걸러 볼 수 있습니다.
- **경영 현황:** 경영진과 같은 화면입니다. 보고 전에 미리 확인할 때 씁니다. (6장 참고)

### 취소

발주와 수주 취소는 오피스 관리자만 할 수 있습니다. 문서 화면 아래 **발주 취소** 또는 **취소**를 누르고 사유를 적습니다. 담당자와 공장에 알림이 갑니다.

## 5. 공장 관리자

공장 관리자는 실물이 움직이는 단계를 맡습니다. 입고와 출고는 공장 관리자만 확정할 수 있고, 사무실은 공장이 확정해야 결과를 알 수 있습니다. 메뉴 **공장 업무**의 세 목록이 하루 일감입니다.

### 발주 확인 (발주 확인 대기)

오피스 승인이 끝난 발주서를 공장 사정에 맞는지 봅니다.

1. 발주서를 열고 수량·납기가 생산 일정과 창고에 맞는지 확인합니다.
2. 맞으면 **공장 확인**을 누릅니다. 담당자가 공급사에 발송할 수 있게 됩니다.
3. 안 맞으면 사유를 적고 **반려**합니다.

### 입고 처리 (입고 대기)

공급사 물건이 공장에 도착하면 처리합니다.

1. 발주서를 열고 품목마다 **입고 수량**을 적습니다. 일부만 왔으면 온 만큼만 적습니다.
2. 수량을 적은 줄에는 **로트번호**를 반드시 적습니다. 제조일, 유통기한, 시험성적서(COA) 메모도 적습니다.
3. **입고 확정**을 누릅니다. 다 들어오면 이카운트 구매 전표가 자동으로 등록되고, 일부만 들어오면 "부분 입고"로 남아 다음 입고를 기다립니다.

### 출고 준비와 출고 (출고 대기)

1. 확정된 수주를 열고 물건을 챙기기 시작하면 **출고 준비 시작**을 누릅니다. 영업과 담당자가 진행을 알 수 있게 됩니다.
2. 차에 실으면 품목마다 **출고 수량**을 적고 **출고 확정**을 누릅니다.
3. 로트는 유통기한이 빠른 것부터 자동으로 빠집니다. 일부만 보내면 "부분 출고"로 남고, 다 보내면 이카운트 판매 전표가 자동으로 등록됩니다.

수주 화면에 "공장에 생산 요청" 기록이 있으면 완제품이 모자라 사무실이 생산을 요청한 건입니다. 생산 일정을 잡아 주세요.

### 재고

- **재고 > 로트·유통기한:** 로트별 남은 수량과 유통기한을 봅니다. 유통기한이 90일 안으로 남은 로트는 따로 표시됩니다.
- **재고 > 품목:** 품목 정보를 조회합니다. 바꿀 것이 있으면 사무실에 이카운트 수정을 요청합니다.

## 6. 경영진

경영진은 로그인하면 바로 **경영 현황**이 열립니다. 문서를 처리하지 않고 숫자와 챙길 일만 봅니다. 위에서 아래로 읽으면 됩니다.

1. **맨 위 한 문장:** 이번 달 수주가 지난달 전체의 몇 % 수준인지 알려 줍니다.
2. **숫자 네 개:** 이번 달 수주, 매입, 고객 주문 수, 납기 준수율. 아래 화살표는 지난달 전체와 비교한 값입니다.
3. **지금 챙길 일:** 납기가 지난 수주·발주, 재고가 모자란 품목, 유통기한이 가까운 로트 금액, 오래 멈춘 승인. 여기 나온 건은 담당 관리자에게 물어보면 됩니다.
4. **한눈에 보는 거래 구조:** 매출 1위 거래처 비중(40% 넘으면 "쏠림 주의"), 매입 1위 공급사 비중(50% 넘으면 "의존 주의"), 가장 많이 팔린 제품, 매입 대비 매출.
5. **거래처와 품목:** 매출처, 매입처, 제품별 매출, 원부재료별 매입의 상위 5개입니다. 원부재료는 평소 단가보다 비싸게 산 경우 ▲로 표시됩니다.
6. **최근 6개월 추세:** 매출과 매입을 억원 단위로 봅니다.

- **버튼이 안 보여요.** 지금은 다른 역할의 차례입니다. 문서 화면의 "지금은 ○○가 ○○할 차례입니다"를 보고 그 사람에게 연락하세요.
